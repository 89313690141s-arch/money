# Импорт: подтверждённые границы

17.11.2026 пользователь сообщил, что примера реальной выписки нет. Поэтому совместимость с выгрузкой Т-Банка не подтверждена. Интерфейс прямо обозначает тестовый CSV-шаблон; не выдавать это за банковскую интеграцию.

Тестовый контракт: UTF-8 (BOM допустим), разделитель `;`, заголовки `Дата;Сумма;Описание;ID`. Дата DD.MM.YYYY или YYYY-MM-DD. Знак суммы: плюс — поступление, минус — списание, рубли с точкой или запятой, не более двух десятичных знаков. ID необязателен. Контрольный пример: -450,01 → расход 45001 копейка; 50000 → доход 5000000 копеек. Нулевые суммы и неверные даты отклоняются.

Поддержаны предпросмотр, выбор типов/категорий, связь перевода со своим вторым счётом, связь возврата с исходной покупкой и пропуск уже существующей записи. Для положительного движения на кредитном счёте по умолчанию предлагается перевод, требуется выбрать источник. Без обязательных связей подтверждение недоступно. Совпадения без стабильного ID требуют ручного решения.

Файл остаётся в памяти браузера; на сервер идут только подтверждённые нормализованные операции. Повтор того же пакета имеет неизменный ключ и ничего не добавляет. Сырые выписки на сервер не загружаются и в логи не записываются. Лимит файла 10 МБ, строк 10000.

Для реальной совместимости нужен обезличенный образец экспорта. После его получения добавить отдельный адаптер с фикстурой и сверкой строк/итогов; не ослаблять проверку формата ради неизвестных колонок. XLSX/PDF и СМС пока не реализованы.
