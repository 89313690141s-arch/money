# Поставка первой версии

Реализуется Next.js + TypeScript, PostgreSQL 17, Prisma 7 и Better Auth. Точные версии зафиксированы в package.json и pnpm-lock.yaml. Документация сверена при старте: https://nextjs.org/docs/app/getting-started/installation, https://better-auth.com/docs/adapters/prisma, https://www.prisma.io/docs/orm/v7.

Локально используется отдельный контейнер PostgreSQL на 127.0.0.1:5440. Вход email/пароль через Better Auth; публичная регистрация закрыта. Аккаунт владельца создаётся только локальной административной командой. Демо — отдельный аккаунт, доступный кнопкой только при явной локальной настройке. Демо не публикуется.

Вместо большого числа преждевременных таблиц финансовые сущности первой личной версии сохраняются в одной типизированной JSONB рабочей области владельца. Проверка ссылок и финансовых инвариантов выполняется на сервере при каждой команде; обновление области и номера версии атомарно в транзакции PostgreSQL. Это позволяет не получить частично обновлённые планы, операции и резервы. Аккаунты входа и сессии остаются отдельными таблицами Better Auth. Совместный доступ и объёмная история потребуют отдельной миграции; сейчас они вне объёма.

Подготовлена поставка Docker Compose + Caddy HTTPS для отдельного Linux-сервера. Конкретный облачный аккаунт, домен и платные ресурсы пользователь не предоставлял; их не создавали. Облачная синхронизация использует тот же серверный API, но доступ с реального iPhone по HTTPS и доступность сети владельца проверяются после размещения. Локальный адрес на компьютере не является ссылкой для iPhone.

Резервные копии AES-256-GCM: ручная локальная команда и ежедневный сервис в production compose, срок хранения 30 дней. Ключ хранить отдельно от резервных копий. Проверка восстановления выполняется в отдельную finance_restore_* базу; замена активной базы автоматически не допускается.
