# Интерфейс

Направление: спокойный личный финансовый инструмент. Палитра: фон #F3F6FA, поверхность #FFFFFF, текст #172B46, план #385DE0, накопления #168475, риск #C25B45. Шрифт — Manrope с кириллицей, локальная поставка, табличные цифры.

Вместо ряда одинаковых карточек — одна широкая полоса распределения денег и рабочая область с графиком, рядом календарь платежей. Навигация слева на компьютере и снизу на телефоне. Всё выравнивается по левому краю; суммы — вправо в таблицах. Заголовки и названия разделов из согласованного описания.

Схема обзора:
```
Навигация | Обзор                 месяц   + Операция
          | Доступно / обязательства / подушка
          | [полоса распределения собственных денег]
          | Расходы по дням       | Ближайшие платежи
          | Последние операции   | Подушка безопасности
```

Самопроверка: убраны декоративные градиенты и одинаковые карточки показателей. Главный выразительный элемент — полоса распределения, она объясняет назначение денег. Красный используется для дефицита, а не для всех покупок. Внешний вид выбран исполнителем в рамках просьбы реализовать современный удобный интерфейс.
