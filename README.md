# Личные финансы

PWA для личного бюджета: план месяца, долги, подушка, операции и аналитика. Данные хранятся на сервере PostgreSQL, не в localStorage.

На уже настроенном компьютере: двойной щелчок по **«Запустить приложение.cmd»**, затем открыть http://localhost:3000. Для собственного бюджета запустить **«Создать личный аккаунт.cmd»**, указать email и пароль, затем войти ими в приложение. Демо открывается отдельной кнопкой на странице входа.

## Локальный запуск

Если забыт пароль: запустить **«Сменить пароль.cmd»** в Проводнике Windows, ввести email существующего аккаунта и новый пароль дважды. Данные бюджета сохраняются, старые сессии завершаются. Это локальная административная команда, удалённого сброса по email нет.

Нужны Node.js 24, pnpm 11 и Docker Desktop.

1. Создать `.env` по `.env.example`: случайные POSTGRES_PASSWORD, BETTER_AUTH_SECRET (не менее 32 символов), BACKUP_KEY (32 байта в hex). Не публиковать `.env`.
2. `pnpm install`
3. `docker compose up -d`
4. `pnpm exec prisma generate`
5. `pnpm run db:migrate`
6. `pnpm run owner:create` — email, имя и пароль запрашиваются интерактивно, пароль скрыт.
7. `pnpm run dev`, открыть http://localhost:3000.

Для локального демо задать LOCAL_DEMO_PASSWORD случайной строкой в `.env`, выполнить `pnpm run demo:create`. Кнопка «Открыть демо с примерами» открывает отдельный аккаунт с вымышленными данными. Для своего бюджета создать отдельного владельца. Повторная demo:create не перезаписывает изменения.

## Проверки

`pnpm test`, `pnpm run typecheck`, `pnpm run lint`, `pnpm run build`.

При запущенном сервере и отдельной локальной базе: `pnpm run test:integration`, `pnpm run test:e2e`. Для браузерных проверок `pnpm exec playwright install chromium`. Тесты создают и удаляют свои аккаунты; браузерные проверки работают с демо. Резервное восстановление использует временную базу finance_restore_test_*.

## Импорт

Тестовый CSV-шаблон скачивается на странице «Счета и импорт». Совместимость с реальной выпиской Т-Банка ещё не подтверждена: примера нет. СМС и пуши не подключены. Любые суммы демо вымышлены.

## Размещение и сохранность

См. [инструкцию эксплуатации](docs/runbook.md). Конфигурация для HTTPS и ежедневного зашифрованного бэкапа подготовлена, облачные ресурсы не создавались. Для установки на реальный iPhone нужно разместить приложение по HTTPS.
